Documentation / Configuration

Environment Variables

What lives in .env versus what's a runtime Admin setting.

Most buyer-facing configuration — payment gateway keys, SMS, social login, branding, SEO — lives in the database and is edited from Admin → Settings, not .env. See the full settings reference for that half. .env covers framework-level and bootstrap-time configuration: things the app needs before it can even reach the database.

Application

VariablePurpose
APP_NAMEInitial display name — Admin → Settings → Branding overrides it at runtime.
APP_ENVproduction on a real install (the installer sets this).
APP_KEYLaravel's encryption key. Generated automatically during install — never share it or commit it.
APP_DEBUGMust be false in production — the installer forces this.
APP_URLYour site's base URL, including https://. Used to generate absolute links, assets, and webhook URLs.
APP_TIMEZONEPlatform default timezone — overridable at runtime from Admin → Settings → General, which then wins.
APP_LOCALE / APP_FALLBACK_LOCALEDefault and fallback UI locale.

Database

DB_CONNECTION (always mysql — MySQL 8.0+ only), DB_HOST, DB_PORT, DB_DATABASE, DB_USERNAME, DB_PASSWORD — all set by the installer's Database step.

Session, queue, cache

SESSION_DRIVER, QUEUE_CONNECTION, and CACHE_STORE all default to database — deliberately, so nothing requires Redis or a service beyond MySQL on shared hosting. See Cache and Cron & queue workers if you want to opt into Redis on a VPS.

Mail (bootstrap defaults only)

MAIL_MAILER, MAIL_HOST, MAIL_PORT, MAIL_USERNAME, MAIL_PASSWORD, MAIL_FROM_ADDRESS, MAIL_FROM_NAME. These only seed the installer's Mail step — once installed, the live values you edit from Admin → Settings → Mail take over and .env is no longer consulted.

Storage / S3 (bootstrap defaults only)

FILESYSTEM_DISK, AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_DEFAULT_REGION, AWS_BUCKET, AWS_USE_PATH_STYLE_ENDPOINT. Same pattern as Mail — see Storage / S3.

Not in .env.example — add these yourself if you need them

VariablePurpose
FCM_CREDENTIALSFilesystem path to your Firebase service-account JSON — required for mobile push notifications. See Firebase & push.
FCM_PROJECT_IDOptional override; normally read straight from the service-account file.
PERFECT_EVENTS_DEMO_MODENever set this on a real install. It's exclusively for a live CodeCanyon-style public demo — it enables demo data reset and locks the shared demo admin account's own credentials.
Never commit .env It contains your database password and app encryption key. It's excluded from the zip and should never be committed to a git repo you push publicly.
