Coupons

Percent or fixed-amount discount codes, scoped to an organizer or a single event.

Both admins and organizers can create coupons — an organizer's are scoped to their own events; an admin can create platform-level ones. A coupon is either scoped to one specific event or to every event by an organizer, whichever fits.

Discount types

TypeHow it's applied
PercentA whole-number percent off the order subtotal (e.g. 10 = 10% off), capped at 100%.
FixedA flat amount off, in your currency's minor units — capped at the subtotal, so a coupon can never push an order negative.

Eligibility rules

A coupon fields all of the following before it's allowed to apply, checked at the moment of checkout:

  • Active — the coupon's own on/off switch.
  • Start date — if set, the coupon isn't usable before it.
  • End date — if set, the coupon isn't usable after it.
  • Max redemptions — if set, the coupon stops working once it's been used that many times total.
  • Minimum order amount — if set, the order subtotal has to meet it for the coupon to apply.
What happens with an ineligible code If a buyer enters a code that fails one of the rules above, checkout doesn't reject the order — it simply proceeds at full price without the discount. There's no error message blocking the purchase over a bad/expired coupon code; the buyer just doesn't get the discount they expected, so it's worth communicating coupon terms clearly wherever you advertise a code.

Tracking redemptions

Each coupon tracks how many times it's been redeemed, which is what the max-redemptions limit checks against. A refunded order that used a coupon releases that redemption back — see Refunds.
