Documentation / Getting Started

Overview

What PerfectEvents is, what's in this documentation, and where to start.

PerfectEvents is a white-label event ticketing platform: a public website where people discover and buy tickets, an Admin panel, an Organizer panel, and a pair of Flutter mobile apps (a customer app for browsing/buying/holding tickets, and a scanner app for door check-in). It's built to be resold and rebranded — one purchase, one deployment, your brand.

How the product is put together

  • The Laravel application (script/) is the whole backend: the public website, the Admin panel, the Organizer panel, and the /api/v1 that the mobile apps talk to. It ships as one install on one server.
  • The mobile apps (flutter/) are optional. Selling entirely through the website works fine without ever touching Flutter. The apps exist for buyers who want a native customer app and/or door-staff scanner app in the app stores under their own name.
Where to start If you're installing for the first time: Server requirements, then the installation wizard. If you only want to change how things look/behave without touching code, read Admin vs. rebuild first — it'll save you time.

Conventions used in these docs

Admin marks something you configure from a panel, no code involved. Rebuild marks something that requires editing source and rebuilding (mobile app icons, for example). Code you type goes in monospace; full commands are in code blocks.
