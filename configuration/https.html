Documentation / Configuration

HTTPS

Required for launch — and the app tightens itself automatically once it's on.

Running without HTTPS is fine for local testing, but not for a real launch — payment gateways, OAuth social login, and browser geolocation/push APIs either require it outright or degrade without it.

Getting a certificate

  • Shared hosting (cPanel) — enable AutoSSL under SSL/TLS Status; most hosts issue a free Let's Encrypt certificate automatically once your domain resolves correctly.
  • VPS — Certbot (certbot --nginx) is the simplest path, or terminate TLS at a load balancer/CDN in front of the app.

Tell the app about it

Set APP_URL=https://yourdomain.com (no trailing slash) in .env. Once the app sees an HTTPS APP_URL, two things change automatically:

  • Session cookies are marked Secure (won't be sent over plain HTTP).
  • The Strict-Transport-Security header is added to every response, instructing browsers to never downgrade back to HTTP for your domain.

Mixed content

If you switch an existing HTTP install to HTTPS after uploads already exist, double check any stored absolute URLs (a custom CMS block with a hardcoded http:// image link, for example) — generated links from the app itself always follow APP_URL, but content an admin typed in by hand won't rewrite itself.
