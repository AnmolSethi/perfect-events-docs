Documentation / Operations

Approvals

Two separate approval layers — organizer accounts, and individual events.

There are two independent things an admin approves: whether someone is allowed to operate as an organizer at all, and whether a given event is allowed to go live. Approving one doesn't approve the other.

Organizer account approval

A new organizer account starts in Pending review. While pending, they can build and edit event drafts, but can't publish anything or appear on the public site. An admin reviews and sets the account to Approved (cleared to operate), Rejected, or later Suspended if an already-approved organizer needs to be pulled.

Event approval

Separately, each event moves through Draft (organizer still editing) → Pending (submitted, awaiting you) → Published (live and publicly discoverable), plus Cancelled and Completed once it's run its course or been called off. Only Published events are visible to buyers.

Whether a submitted event actually needs your review is itself a Admin setting — "Require event approval" (General settings, on by default). With it on, every newly submitted event lands in Pending; with it off, submitting an event publishes it immediately, and this whole page mostly doesn't apply. Either way, an organizer who isn't yet account-approved can't publish at all, regardless of this setting.

Reviewing a pending event

Admin → Events, filtered to Pending, shows the listing exactly as the organizer built it — details, ticket types, pricing, venue, media. From there:

  • Approve — publishes it immediately and clears any earlier moderation note.
  • Send back to draft — requires a reason, stored on the event and shown to the organizer so they know what to fix. This also works on an already-live event, for pulling one back if a problem turns up after the fact.

Editing an event that's already Published does not revert it to Pending — it stays published straight through the edit. Moderation is a one-time gate on getting live in the first place, not a re-review on every change.

Featuring an event

Independently of approval, an admin can mark any event as featured, used for homepage/featured placements. This has no bearing on whether the event is approved or public.
