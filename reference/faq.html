FAQ

Quick answers to the questions buyers ask most before and after installing.

Do I need the mobile apps to sell tickets?

No. The website — public storefront, checkout, Admin, Organizer panel — is fully functional on its own. The Flutter apps are an optional add-on for buyers who want a native customer app and/or a door-staff scanner app in the app stores.

Do I need Composer, Node, or SSH access to install this?

No. The zip ships with vendor/ and built front-end assets already in place — upload, point your domain at script/public, and run the install wizard through a browser. See What's in the box.

Can I use MariaDB instead of MySQL?

No — MySQL 8.0+ specifically. The schema relies on MySQL 8–specific JSON functions and generated columns that MariaDB doesn't implement the same way.

Which payment gateways are supported?

Stripe, PayPal, Razorpay, and Paystack, out of the box — enable as many as you want simultaneously. See Integrations for each one's setup.

Can I add a payment gateway that isn't in the list?

Yes, if you (or a developer you hire) can write a Laravel class — the payment layer is a driver/contract pattern specifically so a new gateway doesn't require touching checkout logic. This is a code change, not something a non-developer can do purely from Admin.

Is there a commission/fee system built in?

Yes — a platform commission percentage (default or per-organizer override) is deducted at payout time. There's no automated money movement, though — payouts are a request/tracking workflow, and you actually pay organizers outside the platform. See Payouts.

Can organizers have custom roles/permissions?

Not in this version — roles are fixed (admin, organizer, staff), though you can adjust which permissions organizer/staff are granted. Custom roles are a planned future feature. See the permissions matrix.

Does it support multiple languages?

Yes — add languages and translate the UI from Admin, and event/organizer content is per-locale on the content itself. See Localization.

Does it support guest checkout?

No, deliberately — an account is required before purchase. This is a locked product decision, not a missing feature.

Can a buyer get a partial refund for just some tickets in an order?

Not yet — refunds are whole-order only in this version. See Refunds.

Is there a built-in backup feature?

No — see Backups for how to back up at the hosting/database level instead.

How do I get support?

Check your CodeCanyon item listing's support policy for how to reach the developer, and the troubleshooting index first for anything covered here.
