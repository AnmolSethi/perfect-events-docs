Documentation / Integrations

PayPal

Orders v2 checkout with a redirect-approve-capture flow.

Configured from Admin → Settings → Payment gateways → PayPal.

Keys you need

FieldNotes
Modesandbox or live — this is PayPal's test-mode toggle, there's no separate test key pair.
Client ID / Client secretFrom your PayPal Developer Dashboard app — sandbox and live apps have separate credentials.
Webhook IDCreated when you register the webhook below.

Webhook URL

https://yourdomain.com/api/v1/webhooks/paypal

Register this in your PayPal app's Webhooks settings, subscribed to at minimum CHECKOUT.ORDER.APPROVED — that event is what actually triggers the payment capture server-side, so checkout only ever resolves through one settled event rather than trusting the client's redirect alone.

How the flow works

The buyer is redirected to PayPal to approve the order; PayPal's webhook firing CHECKOUT.ORDER.APPROVED is what the platform actually captures against — the redirect back to your site is a UX convenience, not the trust boundary.

Test mode

Use sandbox mode with a PayPal sandbox buyer account (create one from the Developer Dashboard → Sandbox → Accounts). Switch to live — with your live app's client ID/secret and a live-registered webhook — before launch.
