Documentation / Mobile Apps

Toolchain Setup

FVM-pinned Flutter and the platform SDKs — get them installed before touching flutter/.

The mobile apps are entirely optional — skip this whole section if you're only selling through the website. If you do want the apps, here's what to install first.

1. Flutter, via FVM

The project pins an exact Flutter version (currently 3.47.2) via FVM (Flutter Version Management), so your local Flutter matches what the app was built and tested against instead of whatever's globally installed.

dart pub global activate fvm
cd flutter/apps/customer   # and again in flutter/apps/scanner
fvm install     # installs the pinned version from .fvmrc
fvm use         # points this project at it

Run every Flutter/Dart command through fvm from here on — fvm flutter run, fvm dart run, etc.

2. Platform SDKs

  • Android — Android Studio (or just the command-line SDK tools) with a recent Android SDK/NDK, on any OS.
  • iOS — Xcode, which means a Mac. This is an Apple requirement, not this product's — there's no way to build or sign an iOS app without one.

3. Verify it worked

Each app is a normal Flutter project. Open flutter/apps/customer (or apps/scanner) in Android Studio or VS Code, or from a terminal:

cd flutter/apps/customer
fvm flutter pub get
fvm flutter analyze   # should print "No issues found!"

If that passes clean, you're set up correctly. See Project structure next for how the pieces fit together.
