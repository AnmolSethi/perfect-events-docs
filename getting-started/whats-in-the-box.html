What's in the Box

The contents of the download, and what each part is for.

perfect-events-vX.Y.Z.zip
├─ Main Files/
│  ├─ script/            ← the Laravel app, WITH vendor/ already installed
│  └─ flutter/            ← Flutter source for the customer + scanner apps (two standalone projects)
├─ Documentation/         ← this documentation site (open Documentation/index.html)
├─ Licensing/
├─ Updates/               ← from v1.1 on: the update package(s) for existing installs
└─ changelog.txt

script/ — the web application

This is everything: the public website, the Admin panel, the Organizer panel, and /api/v1 for the mobile apps. It ships with vendor/ already populated and front-end assets already built (public/build), so a shared-hosting buyer never needs Composer, Node, or SSH access — upload, point your domain at script/public, and run the install wizard. See Installation.

If you're comfortable with Composer and want a smaller upload, you can delete vendor/ and run composer install --no-dev --optimize-autoloader yourself — the app doesn't care which route you took.

flutter/ — the mobile apps

Source only — no prebuilt APK/IPA, since app store binaries have to be signed and branded with your identity, not a generic demo one. You'll need a Mac to build for iOS (an Apple requirement, not this product's). See Mobile Apps for the full setup. Mobile apps are entirely optional — everything sells through the website without them.

Documentation/

This site, as static HTML — open Documentation/index.html in any browser, no server required.

Updates/

Not in the first release. Every later release includes the signed package that updates an existing install from the previous version, installed from Admin → System → Updates. See Updating the product.

What you will need to bring yourself

  • A domain and hosting (shared/cPanel or a VPS) meeting the server requirements
  • Accounts with whichever payment gateway(s), SMTP/SMS provider, and social-login providers you plan to enable
  • A Firebase project, only if you're shipping the mobile apps with push notifications
  • Apple/Google developer accounts, only if you're publishing the mobile apps to the stores
