Documentation / Operations

CMS & Homepage

Pages, FAQ, banners, menus, and homepage section layout — all Admin-editable.

Pages

Static content pages (About, Terms, Privacy, etc.) with a rich-text editor. Content is sanitized on save, so pasted HTML can't be used to inject scripts.

FAQ

A flat list of question/answer entries, shown on a public FAQ page and linked from the troubleshooting/support surfaces of the site.

Banners

Promotional banner images/links, shown wherever the Banners homepage section is placed (see below) — add, reorder, and set an optional link per banner.

Menus

Header/footer navigation items — add links to pages, categories, or external URLs, and control their order.

Homepage sections

The homepage is built from a fixed set of section types — Banners, Featured (events), Upcoming (events), Categories — that you arrange and toggle on/off, rather than a free-form page builder. Each section type pulls its own data live (Featured always shows currently-featured events, Upcoming always shows what's coming up), so there's nothing to keep manually in sync as events change.

Not a drag-and-drop page builder You're arranging and configuring instances of these four section types, not building arbitrary custom layouts block-by-block. For anything beyond what a section type offers, that's a code change — see Admin vs. rebuild.
