Settings Reference

Every Admin → Settings screen, and exactly what it controls.

Almost everything below is database-backed and takes effect immediately on save — no .env equivalent, no redeploy. The two exceptions (Mail, Storage) start from .env/the install wizard but become independently editable here afterward.

ScreenControls
BrandingApp name; brand colors — primary, accent, light-mode and dark-mode page background (each blank = default; hover/tint shades, the dark-mode primary and readable text colors are derived automatically, and apply to the website, both panels, emails, Apple Wallet passes and the mobile apps); logo, favicon; optional separate logos for the public website's header and footer (blank = the main logo).
AppSupport email, support phone — shown in the site footer and structured SEO data; the store IDs and signing fingerprints that make shared links open in the apps; Maps — Google Maps or tiles, and the tile URL and attribution the app's maps use. See Maps & venue locations.
GeneralTimezone, whether buyer reviews auto-approve or need moderation, tax percent + whether it's tax-inclusive, platform commission percent (the payout default), refund window in days (0 = unlimited), whether event approval is required before publishing.
MailSMTP driver/host/port/encryption/credentials/from-address, with a test-email button. See Email (SMTP).
StorageLocal disk or S3 (key/secret/region/bucket/endpoint), with a test button. See Storage & S3.
Payment gatewaysPer-gateway enabled/display-name/credentials for Stripe, PayPal, Razorpay, Paystack. See Integrations.
SMSOn/off + Twilio credentials. See SMS.
Social loginPer-provider (Google/Apple/Facebook) enabled + client id/secret. See Social login.
SEODefault meta description, Google Analytics id, Google Search Console site-verification.
Roles & permissionsWhich of the wireable permissions each role grants. See the permissions matrix.
LanguagesAdd/activate languages, set the default. See Localization.
TranslationsEdit UI chrome strings per language, with JSON export/import.
Modules / UpdatesUnder Admin → System: the built-in modules, and installing a release's update package. See Modules and Updating the product.
SystemNot a settings store — a read-only ops page (PHP/extension checklist, queue health, cron heartbeat, disk usage, recent errors) plus a cache-clear button and the maintenance-mode toggle.

Not covered here (edited elsewhere, but still Admin-level)
