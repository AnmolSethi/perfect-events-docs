Installing on a VPS

Nginx + PHP-FPM + MySQL, with an optional Supervisor-managed queue worker for lower latency.

A VPS gives you two things shared hosting can't: root access, and the option of a persistent queue worker instead of relying purely on the once-a-minute cron drain. Nothing here is required — the shared-hosting-friendly defaults still work fine on a VPS — but if you want the lower-latency setup, this is it.

1. Base packages

Nginx, PHP 8.3+ with the extensions in Server Requirements, MySQL 8.0+, Composer (only if
you're rebuilding vendor/ yourself — not required if you kept the shipped vendor/ folder)

2. Deploy the code

Clone/upload script/ to e.g. /var/www/perfectevents. Point Nginx's document root at /var/www/perfectevents/public:

server {
    listen 80;
    server_name example.com;
    root /var/www/perfectevents/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
        fastcgi_index index.php;
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }

    location ~ /\.(?!well-known).* { deny all; }
}

Set ownership so the web server user can write to storage/ and bootstrap/cache/:

chown -R www-data:www-data /var/www/perfectevents/storage /var/www/perfectevents/bootstrap/cache

3. Create the database, run the wizard

Create a MySQL 8 database and user, then visit your domain and follow the install wizard.

4. Cron (required either way)

# crontab -e
* * * * * php /var/www/perfectevents/artisan schedule:run >> /dev/null 2>&1

5. Optional: Supervisor-managed queue worker

The scheduled queue:work --stop-when-empty --max-time=50 (riding on the cron line above) is enough for shared hosting. On a VPS you can run a persistent worker instead for lower latency on ticket emails/PDFs/pushes — both can coexist safely, the scheduled one just exits immediately if the queue's already empty.

# /etc/supervisor/conf.d/perfectevents-worker.conf
[program:perfectevents-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/perfectevents/artisan queue:work --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
numprocs=2
user=www-data
stopwaitsecs=3600
supervisorctl reread
supervisorctl update
supervisorctl start perfectevents-worker:*

6. HTTPS

Terminate TLS with Certbot/Let's Encrypt (or your load balancer), then set APP_URL=https://… — see HTTPS.
