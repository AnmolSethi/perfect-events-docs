Credits &amp; Licenses

Every third-party package, font, icon set and image that ships in the download, with its license.

Perfect Events is built on open-source software. Each package below keeps its own license; the full license text is inside the package itself (script/vendor/<package>/LICENSE for PHP, and in the package's pub.dev page for the Flutter apps). Versions are the ones locked for this release.
